name: Sub-hub menu shortcut
description: Distinguishes a Sub Hub row's Dashboard action from the global menu shortcut.
---

Keep the Dashboard action on a Sub Hub row or card opening that selected sub-hub's menu admin page. Do not show Menu Management in the global sidebar; the main Dashboard's direct shortcut to Airoli's menu admin is the intended shortcut. Resolve Airoli by name rather than hard-coding its database ID.

**Why:** The user clarified that the Sub Hub Dashboard button already opens the products/categories admin page and later asked to remove the duplicate global sidebar item because the main Dashboard shortcut is sufficient.

**How to apply:** Preserve the row/card route to the selected sub-hub menu and the main Dashboard's Airoli shortcut. Keep the menu page route available for those entry points, but do not restore the sidebar shortcut.
