---
name: Sub-hub menu shortcut
description: Distinguishes a Sub Hub row's Dashboard action from the global menu shortcut.
---

Keep the Dashboard action on a Sub Hub row or card opening that selected sub-hub's menu admin page. The global sidebar should have a separate Menu Management shortcut that opens the last-selected sub-hub's menu and falls back to an available active sub-hub.

**Why:** The user clarified that the Sub Hub Dashboard button already opens the products/categories admin page; the requested change was a separate shortcut in the left sidebar, not redirecting that button to the network dashboard.

**How to apply:** Preserve the row/card route to the selected sub-hub menu. When using that route, store the selected sub-hub so the sidebar shortcut can reopen the same menu.
